# HzSwitcher trailer - assets and provenance

- UI snapshots: rendered from this repository's production WinForms UI and controls. The capture harness supplies simulated monitor/service state; no hardware refresh rates, brightness or personal settings were changed. All product scenes are visibly labelled UI DEMO. Neutral notes and workspace windows are demonstration compositions.
- App icon: the repository's Assets/app.ico, supplied with the project.
- Narration: original approved script, synthesized locally using the installed Microsoft Zira Desktop Windows voice through System.Speech. "HzSwitcher" is pronounced "Hertz Switcher". The voice model/engine is not bundled.
- Music and transitions: original sine-based synthesis composed for this trailer by source/music.py. No commercial music, samples or third-party recordings.
- Pin sounds in the repository are not needed by this edit; the soundtrack supplies the restrained transition effects.
- Typeface: installed Microsoft Segoe UI / Segoe UI Bold, rendered to pixels. Font files are not bundled. Rendering the editable composition requires these fonts or a chosen replacement.
- No stock footage, third-party game footage, personal desktop capture, externally generated imagery or external photos.
- No performance, power-consumption or battery benchmarks are represented. Display values in the labelled demo are simulated examples, not a claim about the viewer's monitor.

The final MP4 is a local production deliverable; no public upload or release has been performed. The gameplay guard is included in installer 1.7.3 and later. The previously packaged 1.7.2 installer predates that guard.
